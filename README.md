# Kernel Quest

A one-day, single-file interactive course on **image convolution** — learn it in ~3.5 hours across 8 worlds plus an exam.

Open `index.html` in any browser, or play the hosted version via GitHub Pages.

## What's inside
- **8 worlds + exam**, each with its own time budget (20 / 15 / 20 / 30 / 40 / 15 / 20 / 30 + 30 min exam).
- **Tutorial-first**: every challenge and boss is gated by a mini-lesson — a diagram and the formula — before the test, with the formula pinned above the question while you answer.
- **Plan clock**: time spent today and time left in the plan; **Fast-track** when you're behind.
- **Breaks** after worlds 3 and 6 with a one-screen recap.
- **Browser-saved progress** (localStorage, same-day) and a **print-friendly end-of-day summary** of every formula, filter, and missed question.

### Curriculum
1. Slide, multiply, add · 2. Sizes and borders · 3. Convolution vs correlation · 4. Blur · 5. Edges · 6. Name that filter · 7. Speed · 8. Scales and theory.

Single HTML file, no build step, no dependencies.
